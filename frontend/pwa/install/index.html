Установка из Chrome

  1. Откройте эту страницу в Chrome на Android.
  2. Нажмите кнопку установки или меню ⋮ → Добавить на главный экран → Установить.
  3. Запустите Server Deck с экрана телефона и войдите в свою учётную запись.

Приложение работает через интернет. Используйте тот же логин и пароль, что и в веб-панели. Обновления интерфейса приходят автоматически.
